How it works

  1. 01 Paste the job description

    Include the requirements and nice-to-haves. The more complete the posting, the sharper the comparison.

  2. 02 Upload a resume

    Any PDF works, including scanned copies. The file goes to an n8n workflow that sends it to Google Gemini.

  3. 03 Get the fit analysis

    Gemini checks each requirement against the resume and returns a score, matched and missing skills, and next steps.
